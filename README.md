# Daybloom 0.1.8

A visual, sectograph-style day planner and timer.

> **Releases now live at [alshell7/daybloom](https://github.com/alshell7/daybloom/releases).**
> This feed stays at 0.1.8 so copies older than it can update once; from 0.1.8 on,
> Daybloom updates itself from there.

## macOS (Apple silicon + Intel)
- [Daybloom_0.1.8_universal.dmg](https://raw.githubusercontent.com/alshell7/daybloom-releases/main/Daybloom_0.1.8_universal.dmg)

Not notarised yet. The first time, macOS stops the app:

1. Open **System Settings › Privacy & Security**.
2. Scroll to **Security**. Click **Open Anyway** next to the Daybloom message.
